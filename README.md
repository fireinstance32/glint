## ✨ What is Glint?

Glint is a fast, good-looking notes app for Windows. Type like you would in Notepad, then
paste or drop in images, videos and web links — and drag them **anywhere on the page**.
Everything is stored as normal `.md` files in a folder you choose, so your notes are never
locked in (they open fine in Obsidian, VS Code or any text editor).

## 🖼️ Pictures, videos & links

- 🖼️ **Free-form media** — drag pictures, videos and link cards anywhere on the page
- 📌 **Stays with your text** — add lines above an image and it moves down with them
- 📋 **Paste anything** — screenshots, image files, videos, or a web address
- 🌐 **Reference cards** — paste a link and get its title, preview image and summary
- ↔️ **Resize by dragging**, double-click to add a caption, Alt+arrows to nudge
- ↩️ **Undo everything** — moves, resizes and deletes included
- ✏️ **Image editor** — crop, rotate, flip, draw, arrows, text and pixelate (originals are kept)
- 🔍 **Full-size viewer**, ▢ **frames** (rounded, shadow, polaroid, circle…) and 📐 **snap guides**

## 🗂️ Notes & organising

- 📁 **Notes sidebar** with folders (drag notes between them), full-text search and `#tags`
- ✎ **Rename** a note (F2) and every link to it updates itself
- 📌 **Pinned notes**, 🎨 **tag colours**, 🧩 **templates** and a 🗑️ **trash** you can restore from
- 🔗 **`[[Links]]` between notes**, with backlinks showing what links here
- 🔎 **Jump to note** (Ctrl+J) — type a few letters, press Enter
- 📅 **Today's note** (Ctrl+D) — a fresh page for the day, one click away
- 🕘 **Recent files** and **reopen closed tab** (Ctrl+Shift+T)

## ✍️ Writing

- ☑️ **Checklists** — Ctrl+L, click the box to tick it
- • **Lists continue** when you press Enter
- 👁️ **Markdown preview** (Ctrl+E) for a clean read-only view
- 🔍 **Find & replace**, word count, zoom, spell check, focus mode
- 📄 **Export to PDF** (Ctrl+P)

## 💾 Never lose anything

- 💾 **Save button** that shows *Save → Saving… → ✓ Saved*
- ⚡ **Autosave** for notes that already have a file
- 🧷 **Crash-safe sessions** — reopen Glint and your tabs are exactly as you left them
- 📝 **Plain Markdown files**, images kept next to the note in a `.assets` folder

## 🎨 Make it yours

- 📄 **Paper** theme by default, plus Aurora, Midnight, Sunset, Forest and Light
- 🎨 **Solid colours** (ink, red, orange, yellow, green, teal, purple, pink, brown, graphite) or **gradients**
- 🔤 Choice of fonts, text size and line spacing
- 🧰 **Toolbar** for everything — no shortcuts to memorise (but there's a sheet: Ctrl+/)

## 🔄 Automatic updates

Glint checks for new versions in the background. When one is ready you'll see
**“Restart now / Later”** — and after restarting, a short ✨ *What's new* list.

## ⬇️ Install

1. Go to **[Releases](https://github.com/fireinstance32/glint/releases/latest)** and download `Glint-Setup-x.y.z.exe`
2. Run it. Windows may say *“Unknown publisher”* → click **More info → Run anyway**
   (the app isn't code-signed yet)
3. Done — future updates arrive by themselves 🎉

> Already on **0.2.0**? Install the latest version once by hand; that older version didn't
> have the updater yet. From then on it's automatic.
