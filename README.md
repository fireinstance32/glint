## ✨ Why Glint

- 🖼️ **Pictures anywhere**: paste or drop images, videos and links, then drag them wherever you like
- ✍️ **Styles itself as you type**: headings, **bold**, *italic*, highlights, checklists and tables, with no clutter
- 🕸️ **Linked notes**: `[[link]]` your notes together and explore them in a glowing graph
- 🛡️ **Never lose a word**: autosave, version history, daily backups and crash-safe tabs
- 🎨 **Make it yours**: themes, colours, fonts and candy gradient frames
- 📝 **Your files, forever**: plain Markdown in a folder you choose, so they open anywhere

## ⬇️ Install

1. Download `Glint-Setup-1.0.0.exe` from **[Releases](https://github.com/fireinstance32/glint/releases/latest)**
2. Run it. If Windows says *"Unknown publisher"*, click **More info → Run anyway**
3. That's it. Updates arrive by themselves 🎉

New here? Glint opens with a short welcome note that shows you around.
